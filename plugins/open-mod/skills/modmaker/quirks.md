# Known Quirks — STS2 / BaseLib gotchas

Non-obvious behaviors that silently break STS2 mods. Read before writing any C#.
These pair with the sts2-api `errors.md` (error signature → fix); this file is the
"know it up front" version. Confirmed against decompiled `sts2.dll` + BaseLib 3.3.2
during M1.

## Registration

- **Custom characters register in the BaseLib constructor.** In BaseLib 3.3.5,
  `CustomCharacterModel()` calls `CustomContentDictionary.AddCharacter(this)`.
  A class inheriting `PlaceholderCharacterModel` must not call `AddCharacter` manually.
- **`[Pool(...)]` is mandatory** on every `CustomRelicModel` subclass. BaseLib
  auto-registers custom models in their ctor and **throws at startup** without a
  pool attribute. `using BaseLib.Utils;` for `[Pool]`,
  `using MegaCrit.Sts2.Core.Models.RelicPools;` for the pool types
  (`SharedRelicPool` = colorless default).

## Localization key derivation (the #1 silent failure)

- The relic's real `Id.Entry` is **`<PREFIX>-<SLUG>`**, and loc keys / icon names
  derive from it:
  - `SLUG = Slugify(ClassName)` = CamelCase split + UPPER_SNAKE. `GamblersCoin` → `GAMBLERS_COIN`.
  - `PREFIX = <first namespace segment>.ToUpperInvariant()`. Namespace `GamblersCoin.*` → `GAMBLERSCOIN`.
  - Final: `GAMBLERSCOIN-GAMBLERS_COIN`.
- `relics.json` keys are **flat strings** (`"<PREFIX>-<SLUG>.title"`), NOT nested
  JSON. The `relics` LocTable is a flat `Dictionary<string,string>`.
- Get this wrong → the relic shows the raw key or blank text, with no error.
- Pin an exact id with `[CustomID("EXACT-ID")]` if you must override the derivation.
- Icon file = prefix-stripped, lowercased slug → `images/relics/<slug>.png`
  (+ `_outline`, + `big/`); falls back to `relic.png` if missing.

## Combat hooks

- **Combat-start energy MUST use `AfterSideTurnStart` + `TurnNumber <= 1`**, never
  `BeforeCombatStart()`. The turn-1 energy reset wipes anything granted earlier.
  Vanilla `Lantern` does it this way.
- `AfterSideTurnStart` fires **for every side and every turn**. Always guard with
  `participants.Contains(Owner.Creature)` (right owner, matters in multiplayer) and,
  for "start of combat", `Owner.PlayerCombatState!.TurnNumber <= 1` (else it re-fires each turn).
- Relics receive combat hooks automatically (`RelicModel.ShouldReceiveCombatHooks => true`).
  There is **no `ICombatHook` interface to implement** — just override the method.

## Nullable

- `Owner.PlayerCombatState` is typed `PlayerCombatState?` (null outside combat) but
  is non-null inside a combat hook. Capture once with the null-forgiving operator to
  silence `CS8602`: `var combat = Owner.PlayerCombatState!;` then use `combat.Energy`,
  `combat.TurnNumber`.

## RNG

- **Never `System.Random`** — it breaks determinism and seed sharing. Use
  `MegaCrit.Sts2.Core.Random.Rng`: `new Rng(Owner, base.Id)`; `.NextBool()` (50/50),
  `.NextInt(maxExcl)`. Add a mixin (`new Rng(Owner, base.Id, (uint)turn)`) if it may
  roll repeatedly and you want distinct results.

## Build / toolchain

- **PckPacker ships commented out** in the template csproj. Uncomment it or you get
  no `.pck` — and localization/images won't appear in-game. No MegaDot needed.
- If passing MSBuild props on a `publish` command, use `--property:Name=Value`, not
  `/p:Name=Value` (the latter gets mangled by shell quoting → MSB1008). The normal
  `dotnet build -c Release` path needs no props.

## Dev console (verification)

- Open with **`` ` `` (backtick)** — also `'`, `*`, `^`, `Shift+8`; close with `Esc`.
- Debug commands (`relic add <id>`, `energy`, ...) are enabled only when the game is
  **running modded** (`ModManager.IsRunningModded()`), true whenever ≥1 gameplay mod
  loaded. If commands are missing, confirm the mod actually loaded (grep log for
  `RUNNING MODDED`).
- `relic add` matching is `Contains`, uppercased — a unique substring works.

## Feedback loop

New quirks discovered during a real build go into the project's `MEMORY.md` first.
Recurring ones get promoted here and into `errors.md` (append-only) by the skill
maintainer. Do not edit this file from inside a generated mod project.
