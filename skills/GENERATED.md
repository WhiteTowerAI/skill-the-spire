# Generated skills payload - do not hand-edit

This directory is generated by `publish.sh` from `games/sts2/skills/` and
`games/sts2/tools/`. It is the one shipped skill tree: `npx skills add` discovers it, and the
Codex (`.codex-plugin/`) and Claude Code (`.claude-plugin/`) plugin manifests at the repository
root both load it.

- `skills/modmaker/` contains the main workflow and bundled cross-platform tools.
- `skills/sts2api/` contains the grounded STS2 and RitsuLib reference pack.

Edit authoritative source, then run `./publish.sh --force`.
