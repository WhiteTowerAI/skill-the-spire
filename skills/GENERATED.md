# Generated skills payload - do not hand-edit

This directory is generated by `publish.sh` from `games/sts2/skills/`, `games/sts2/tools/`,
and the plugin manifests in `scripts/publish/`. It is the one shipped skill tree:
`npx skills add` discovers it, and it is the plugin root for both Codex
(`.codex-plugin/plugin.json`) and Claude Code (`.claude-plugin/plugin.json`).

- `skills/modmaker/` contains the main workflow and bundled cross-platform tools.
- `skills/sts2api/` contains the grounded STS2 and RitsuLib reference pack.

Edit authoritative source, then run `./publish.sh --force`.
